# Sahmi Kasban Mobile

تطبيق Flutter العربي الخاص بمشروع سهمي كسبان.

## الحالة الحالية

هذه هي الدفعة الأولى من المرحلة 4، وتشمل:

- Splash وOnboarding محفوظ محليًا.
- تسجيل الحساب وتسجيل الدخول.
- تخزين Access وRefresh tokens باستخدام `flutter_secure_storage`.
- تجديد تلقائي للـAccess Token عند استجابة `401`.
- حماية التنقل حسب حالة الجلسة.
- Dashboard بأقسام الرئيسية، تحليل سهم، المحفظة، وحسابي.
- تحميل Profile وWallet ومقدمة تقرير أفضل 10 من الـBackend.
- دعم السحب للتحديث ورسائل فشل الشبكة.

## إعداد منصات Flutter

مجلد `mobile/` يحتوي كود التطبيق وملف الحزم. لإنشاء ملفات Android وiOS المحلية لأول مرة:

```bash
cd mobile
flutter create --project-name sahmi_kasban_mobile --platforms=android,ios .
```

الأمر ينشئ ملفات المنصات المفقودة مع الإبقاء على كود `lib/` الحالي.

## التشغيل

```bash
cd mobile
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

- Android Emulator يستخدم `10.0.2.2` للوصول إلى الخادم المحلي.
- على جهاز حقيقي استخدم عنوان IP لجهاز التطوير داخل الشبكة.
- عنوان الإنتاج يجب تمريره من إعدادات البناء، ولا يوضع ثابتًا داخل الكود.

## الفحص

```bash
dart format --output=none --set-exit-if-changed lib test
flutter analyze
flutter test
```
