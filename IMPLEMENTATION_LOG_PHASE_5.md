## مبادئ الأمان المعتمدة

- Flutter لا يمنح العملات ولا يفعّل الاشتراك بنفسه.
- `purchaseToken` يُرسل إلى Backend ويُتحقق منه مع Google Play قبل منح أي Entitlement.
- `purchaseToken` فريد عالميًا في قاعدة البيانات ويمنع استخدامه لمستخدم أو منتج آخر.
- التوكن يُخزن مشفرًا، مع تخزين SHA-256 منفصل للفهرسة ومنع التكرار.
- العملات من Rewarded Ads لا تُضاف من `onUserEarnedReward` وحده.
- كل إعلان يبدأ بجلسة قصيرة صادرة من Backend، ويرسل معرفها العشوائي داخل `custom_data`.
- المكافأة تُضاف فقط بعد AdMob Server-Side Verification موقّع.
- بيئات Staging وProduction ترفض Stub Mode وإعلانات Google التجريبية تلقائيًا.

### rewarded_ad_claims

كل SSV ناجح له `transaction_id` فريد وجلسة واحدة وWallet transaction واحدة، ما يمنع المكافأة المكررة.

## Rewarded Ads rules

- مكافأة السيرفر: 75 نقطة = 0.75 عملة.
- الحد اليومي: 4 مكافآت.
- Cooldown الافتراضي: 15 دقيقة.
- مدة جلسة الإعلان: 15 دقيقة.
- التوقيت اليومي محسوب حسب `Africa/Cairo`.
- الخطط بلا إعلانات لا يمكنها إنشاء جلسة Rewarded Ad.
- الاختبارات والتطوير يستخدمان Test Ad Unit IDs الرسمية فقط.

## Google Play verification

تمت إضافة ثلاثة أوضاع:

- `disabled`: الوضع الافتراضي حتى إضافة الإعدادات.
- `stub`: للاختبارات والتطوير المحلي فقط.
- `live`: يستخدم Google Play Developer API وحساب Service Account.

في Staging وProduction يجب أن يكون الوضع `live` مع:

```text
GOOGLE_PLAY_SERVICE_ACCOUNT_JSON
BILLING_TOKEN_ENCRYPTION_KEY
GOOGLE_PLAY_PACKAGE_NAME
```

الشراء المكتمل فقط يمنح Entitlement. Pending أو cancelled أو expired لا يمنح شيئًا.

## Tests added

- Coin pack purchase grants points once.
- Repeating the same token is idempotent.
- A token cannot move to a different user.
- Subscription product activates the server-side plan definition.
- An expired paid subscription falls back to the always-active free plan.
- Rewarded-ad callback credits the fixed server reward once.
- Duplicate AdMob transaction does not duplicate points.
- Four-reward daily limit is enforced.
- Paid/no-ad subscription cannot request rewarded ads.
- Stub SSV requires an explicit test signature.
- Purchase tokens are encrypted at rest.
